# 🤖 Pharaonic Chatbot Component — دليل فريق الشات بوت

هذا المجلد يحتوي على **مكون الشات بوت الفرعوني (حكيم مصر)** المنفصل تماماً عن كود الموقع الرئيسي.

## 📁 محتويات المجلد:
- `chatbot.js`: المنطق البرمجي للمحادثة، إدارة النافذة، والاتصال بالخادم.
- `chatbot.css`: التصميم الفرعوني الأنيق (ألوان الذهب، أزرق اللازورد، والرمال).
- `README.md`: هذا الملف الإرشادي.

---

## 🔌 كيف يقوم فريق الشات بوت بربط شغلهم؟

### 1. الخيار الأول (الأبسط): ربط السيرفر الخاص بكم بملف `chatbot.js`
افتح ملف `chatbot.js` وقم بتعديل الإعدادات في أول الملف:
```javascript
window.EhkyChatbotConfig = {
  // 1. فعّل الاتصال بالـ API الحقيقي
  USE_REMOTE_API: true,
  
  // 2. ضع رابط الـ API / Webhook الذي بنيتموه:
  apiUrl: 'http://localhost:5000/api/chat', // أو رابط سيرفركم
  
  // 3. يمكنك تغيير النصوص والأفاتار إذا رغبتم
  botName: 'حكيم مصر',
  botTitle: 'المرشد التراثي الذكي'
};
```

#### شكل البيانات المتوقع إرسالها واستقبالها (Request & Response):
- **Request (POST JSON):**
  ```json
  {
    "message": "ما هي صناعة المراكب بالإسكندرية؟"
  }
  ```
- **Expected Response (JSON):**
  ```json
  {
    "reply": "صناعة المراكب بالإسكندرية من أقدم الحرف في الأنفوشي وأبو قير..."
  }
  ```

---

### 2. الخيار الثاني: استبدال الشات بالكامل بـ SDK أو Widget خارجي
إذا كنتم تبنون الشات بواسطة (Botpress, Voiceflow, LangChain, أو React Widget):
- يمكنكم استبدال محتوى هذا المجلد (`frontend/components/chatbot/`) بحزمتكم الخاصة.
- الشيء الوحيد الذي يحتاجه الفرونت إند هو إتاحة دالة:
  ```javascript
  window.openEhkyChatbot(optionalQuestion);
  ```
  حتى تعمل أزرار "اسأل عن الحرفة" الموجودة داخل صفحات الموقع بشكل تلقائي!
