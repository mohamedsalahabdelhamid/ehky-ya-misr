# 🗄️ Database & API Integration Guide — دليل فريق قاعدة البيانات

مرحباً يا شباب! هذا الملف يشرح لفريق قاعدة البيانات والباك إند كيفية بناء الـ Endpoints والـ Data Schema لربطها بالفرونت إند بكل سهولة.

---

## 🔄 الوضع الذكي: أوفلاين / أونلاين (جديد)

الفرونت إند يعمل الآن بنمطين تلقائيين حسب طريقة فتح الموقع:

| طريقة التشغيل | مصدر البيانات | مصدر الفيديو |
|---|---|---|
| فتح `index.html` مباشرة (`file://`) | البيانات المدمجة `LOCAL_*` | ملفات `local_videos/` المحلية |
| تشغيله عبر سيرفر / استضافة (`http/https`) | الـ API (مع سقوط تلقائي للبيانات المحلية) | بث يوتيوب |

**كيف يقرر الفرونت إند؟** في ملف `frontend/js/services/heritageService.js`:

```javascript
const DATABASE_MODE = 'auto'; // 'auto' | true | false
```

- `'auto'` (الافتراضي): يكتشف البروتوكول تلقائياً كما في الجدول أعلاه.
- `true`: يفرض استخدام الـ API دائماً (للاختبار عند فريق الداتا بيز).
- `false`: يفرض البيانات المحلية دائماً (عرض أوفلاين 100%).

**فحص الصحة Health Check:** عند أول طلب في الجلسة (وفقط مرة واحدة، والنتيجة تُخزَّن مؤقتاً) يستعلم الفرونت إند عن `GET /api/health`:
- إذا نجح → يسحب البيانات من الـ API.
- إذا فشل (سيرفر نائم في الاستضافات المجانية، أو غير منشور) → يكمل فوراً على البيانات المحلية بدون أي انتظار ملحوظ للمستخدم.

---

## 🎯 كيف تتصلون بالفرونت إند عند النشر؟

غيّروا سطراً واحداً فقط في `frontend/js/services/heritageService.js`:

```javascript
API_BASE_URL: 'https://your-backend-url.onrender.com/api'
```

(محلياً: `http://localhost:5000/api`)

## 📡 الـ Endpoints المطلوبة (والمطبّقة فعلاً في `backend/`)

### 1. جلب قائمة المحافظات
- **الطلب:** `GET /api/provinces`
- **شكل الـ JSON المتوقع (Array):**
```json
[
  {
    "id": "alex",
    "name": "الإسكندرية",
    "path": "M257 89L325 106L351 116L350 128L326 126L307 119L296 115L270 107Z",
    "cx": 303,
    "cy": 102,
    "mapPos": [36, 12]
  }
]
```

### 2. البحث والفلترة في عناصر التراث
- **الطلب:** `GET /api/heritage?category=craft&province=alex&era=all&search=مراكب`
- **ملاحظة:** الفلاتر `category` و `province` و `era` و `search` كلها مطبّقة في السيرفر (البحث بالعربية يتجاهل الهمزات والتاء المربوطة).
- **شكل الـ JSON المتوقع (Array of Items):**
```json
[
  {
    "id": "boats",
    "title": "صناعة المراكب",
    "category": "craft",
    "provinceId": "alex",
    "provinceName": "الإسكندرية",
    "regions": "أبو قير — الأنفوشي",
    "summary": "من تجهيز الخشب إلى بناء الهيكل والتشطيب…",
    "status": "سجل موثق"
  }
]
```

### 3. جلب تفاصيل حرفة أو عنصر تراثي كامل
- **الطلب:** `GET /api/crafts/:id` (مثلاً `GET /api/crafts/boats`)
- **شكل الـ JSON المتوقع:**
```json
{
  "id": "boats",
  "title": "صناعة المراكب",
  "category": "craft",
  "provinceId": "alex",
  "provinceName": "الإسكندرية",
  "regions": "أبو قير — الأنفوشي",
  "status": "سجل موثق",
  "summary": "ملخص الحرفة...",
  "description": "الوصف الكامل...",
  "materials": "الخامات والأدوات...",
  "steps": [
    "تجهيز الأخشاب...",
    "بناء الهيكل..."
  ]
}
```

### 4. الأطباق والأطعمة
- **القائمة مع الفلاتر:** `GET /api/foods?province=alex&search=كبدة`
- **عنصر واحد:** `GET /api/foods/:id`

### 5. الحرفيين
- **القائمة مع الفلاتر:** `GET /api/artisans?craftId=arabesque&provinceId=cairo`
- **عنصر واحد:** `GET /api/artisans/:id`

### 6. فحص الصحة
- **الطلب:** `GET /api/health` → `{"status":"online",...}` (يستخدمه الفرونت إند لقرار الربط)

---

## 💡 ميزة رائعة:
إذا تعطل السيرفر أو لم تنتهوا من بعض الـ Endpoints، فإن كود `heritageService.js` مصمم بحيث يسقط تلقائياً (Graceful Fallback) على البيانات المحلية المؤقتة دون أن يتوقف الموقع عن العمل أو تظهر شاشة بيضاء! وكل سقوط يُسجَّل في الـ Console كتحذير `console.warn` ليسهل تشخيص المشكلة.
