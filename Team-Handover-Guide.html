🏛️ مشروع «احكي يا مصر» — دليل تكامل الفرق وتوزيع المهام

المعمارية المعزولة: دليل المطورين لفرق (الفرونت إند • الشات بوت والذكاء الاصطناعي • قاعدة البيانات والباك إند)
معمارية مفصولة بالكامل الفرونت يعمل بدون سيرفر عزل تام للملفات (Zero Conflict) جاهز لربط الـ APIs

تم تصميم هذه المعمارية خصيصاً لتمكين ثلاثة تيمات مختلفة من العمل في نفس الوقت بالتوازي (Parallel Development) دون أن ينتظر أحد أحداً، ودون أن يمسح تيم شغل الآخر أو يتسبب في تضارب ملفات (Merge Conflicts).

2. التفاصيل الدقيقة لمهام كل فريق

🎨 أ. فريق الفرونت إند (Frontend & UI/UX Developers)

المجلد: frontend/

طبيعة العمل: تطوير الواجهات، الصفحات، الألوان، الخريطة، والتجاوب مع شاشات الموبايل.

  • التشغيل المستقل: يمكنكم فتح ملف frontend/index.html مباشرة بنقرة مزدوجة في أي متصفح دون تشغيل أي خادم أو بايثون.
  • تطوير الصفحات والتصميم: كل التعديلات البصرية تكتب داخل frontend/css/style.css.
  • التنقل والصفحات: يتم التحكم بالمسارات (Routes) من خلال frontend/js/app.js.
  • إضافة الصور والمشاهد: توضع جميع الصور داخل مجلد frontend/assets/.
⚠️ تنبيه أمان لتيم الفرونت إند: لا تقم بتعديل أو حذف الملفين frontend/components/chatbot/ أو frontend/js/services/heritageService.js لأن هذين الملفين مخصصان لتيم الشات بوت والداتا بيز لربط خدماتهم.

🤖 ب. فريق الشات بوت والذكاء الاصطناعي (AI & Chatbot Team)

المجلد: frontend/components/chatbot/

طبيعة العمل: برمجة "حكيم مصر" (المرشد الفرعوني)، هندسة الأوامر (Prompt Engineering)، وربط نماذج الذكاء الاصطناعي (Gemini / OpenAI / LangChain).

  • الأفاتار الفرعوني الملكي: تم إعداد أفاتار فرعوني عالي الجودة باسم pharaoh-avatar.svg جاهز ومربوط مسبقاً.
  • كود الشات المنفصل: كل منطق الشات موجود داخل frontend/components/chatbot/chatbot.js.
  • تنسيقات الشات: ألوان الذهب واللازورد موجودة داخل chatbot.css ويمكن تخصيصها دون لمس باقي الموقع.
  • في الباك إند: متاح لكم ملف backend/controllers/chatController.js لوضع مفتاح الـ API والاتصال بنموذج الذكاء الاصطناعي.

كيف يربط فريق الشات بوت شغلهم بالفرونت إند؟

عند اكتمال نموذج الذكاء الاصطناعي، يفتح الفريق ملف chatbot.js ويعدل السطور الأولى فقط:

window.EhkyChatbotConfig = { USE_REMOTE_API: true, // تفعيل الربط السحابي بالذكاء الاصطناعي apiUrl: 'http://localhost:5000/api/chat', // رابط سيرفركم botName: 'حكيم مصر' };

🗄️ ج. فريق قاعدة البيانات والباك إند (Database & Backend Team)

المجلد: backend/

طبيعة العمل: بناء جداول قاعدة البيانات (PostgreSQL / MongoDB / MySQL)، وحفظ استمارات التوثيق وبناء مسارات الـ REST API.

  • الملفات المخصصة لهم: مجلد backend/ بالكامل، وملف الدليل الشامل frontend/js/services/DATABASE_INTEGRATION.md.
  • الخادم المجهز: سيرفر Express مبني بالكامل في backend/server.js مع تقسيم احترافي للـ Routes والـ Controllers.
  • الـ Endpoints الأربعة المطلوبة:
    • GET /api/provinces — قائمة المحافظات الـ 27
    • GET /api/heritage — فلترة وبحث التراث (حرف، مأكولات، فنون)
    • GET /api/crafts/:id — استرجاع تفاصيل الحرفة وبيانات التوثيق
    • POST /api/chat — نقطة استقبال استفسارات الشات بوت

كيف يربط فريق قاعدة البيانات شغلهم بالفرونت إند؟

بمجرد جهوزية الـ API، يفتح الفريق ملف frontend/js/services/heritageService.js ويغيرون فقط:

const DATABASE_CONFIG = { USE_REMOTE_API: true, // تفعيل جلب البيانات الحية من قاعدة البيانات API_BASE_URL: 'http://localhost:5000/api' // رابط سيرفر قاعدة البيانات };

3. خطة العمل الجماعي عبر Git (Conflict-Free Workflow)

لضمان عدم حدوث أي تضارب عند دمج الأكواد، يوصى باتباع نظام الفروع الآتي:

  • main: الفرع الرئيسي المستقر، لا يتم الرفع المباشر عليه إلا بعد الفحص.
  • feature/frontend-ui: يعمل عليه مطورو الفرونت إند بحرية.
  • feature/chatbot-ai: يعمل عليه مطورو الشات بوت داخل مجلد components/chatbot/.
  • feature/database-backend: يعمل عليه مطورو الباك إند داخل مجلد backend/.

4. أدوات الفحص المرفقة

تم تزويد المشروع بأداتين مدمجتين لتسهيل العمل:

  • open-frontend.bat: يفتح الفرونت إند بنقرة واحدة في المتصفح للاختبار السريع بدون سيرفر.
  • test-integration.html: لوحة فحص تفاعلية تبين بنقاط خضراء وحمراء حالة عمل كل من الفرونت، الشات بوت، وسيرفر قاعدة البيانات.
